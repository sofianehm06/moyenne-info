# 🎓 Moyenne Info — Calculateur de moyenne universitaire

Application mobile Flutter pour les étudiants du département Informatique.

[![Télécharger l'APK](https://img.shields.io/badge/T%C3%A9l%C3%A9charger-APK-brightgreen)](https://github.com/sofianehm06/moyenne-info/releases/latest)

## 📱 Aperçu

Moyenne Info permet de calculer automatiquement sa moyenne semestrielle et annuelle en saisissant ses notes de TP, TD et examen final. L'app prend en compte les coefficients, crédits et pondérations CC/Examen de chaque matière.

## ✨ Fonctionnalités

- 📊 Calcul de moyenne par matière, UE et semestre
- 🎯 Mode simulation : note minimale à l'exam pour atteindre un objectif
- ✏️ Modules personnalisables (coefficient, pondération CC/Examen)
- ➕ Ajout de modules manquants
- 🏫 Filières supportées : L1/L2/L3, M1/M2 (GL, IA, ASR), Cycle Ingénieur

## ⬇️ Télécharger (Android)

1. Ouvre la page [Releases](https://github.com/sofianehm06/moyenne-info/releases/latest).
2. Télécharge le fichier `.apk` dans la section **Assets**.
3. Ouvre-le sur ton téléphone et autorise l'installation depuis cette source si Android le demande.

Les APK officiels sont publiés **uniquement** sur la page Releases de ce dépôt.

## 🔐 Vérifier l'authenticité

- Empreinte SHA-256 du certificat de signature : `À COMPLÉTER`
- Somme SHA-256 de chaque APK : indiquée dans les notes de chaque version.

```bash
cd moyenne-info

flutter run
```
